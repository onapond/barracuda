# Kickoff: Homepage Korean-Original Copy Cycle
Date: 2026-03-24
Route scope: `/` (homepage only)
Status: In progress

## Cycle goal (primary)
Rewrite homepage copy from scratch in Korean so it reads as native Korean writing, not English-first translation.

## Out of scope (this tranche)
- Code integration
- Typography / line-break optimization
- Responsive QA
- Subpage expansion

## Homepage job (one sentence)
바라쿠다는 “커피보다 장면이 남는 공간”이라는 정체성을 5초 안에 이해시키고, 공간 탐색/문의로 자연스럽게 연결한다.

## Definition: Korean-originalness (pass criteria)
- 문장을 소리 내 읽었을 때 어색한 번역투가 없다.
- 한 문장에 주장 1개만 담는다.
- 추상 명사(인상/감도/경험/가치)로 “프리미엄”을 주장하지 않는다.
- 구조 습관어로 의미를 이어 붙이지 않는다(예: `~을/를 통해`, `~중심으로`, `~로 이어집니다`, `~을 담았습니다`).
- 문장 호흡이 한국어답고 단정하다(불필요한 접속/수식 최소).

## Homepage sections in scope
- Header: site name/로고, nav labels(현재 영문 유지 여부 결정은 KCE에서 판단)
- Hero: title, description, primary CTA, hero image alt
- Intro (Space): eyebrow, title, description, CTA
- Signature tabs section: eyebrow, section title/description, per-tab title/description/CTA, per-media alt
- Previews: `Space / Brand / Coffee / Menu / Visit` 각 eyebrow/title/description/CTA
- Footer: statement, subline (주소/저작권은 사실 유지)
