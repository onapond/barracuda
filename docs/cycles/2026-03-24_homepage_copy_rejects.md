# KCE Rejects: Homepage (`/`)
Date: 2026-03-24
Role: Korean Copy Editor (KCE)
Scope: homepage only

Format
- Rejected string
- Reason (Korean-originalness / vagueness / repetition / English-first logic)
- Rewrite direction (what to do instead)

## 0) Header / Nav labels
Deferred decision (not a block for copy quality)
- Rejected: `프라이빗 씬`
  - Reason: category UI label feels forced; English category label is already the system.
  - Direction: keep English category name; make the copy Korean.

## 1) Hero
- Rejected (previously approved): `조용한 모임부터 기념의 밤까지, 바라쿠다는 장면이 남는 공간입니다.`
  - Reason: repeats the hero title’s slogan logic (“장면이 남는”) instead of sharpening meaning; reads like a campaign line.
  - Direction: keep the title as the single “scene stays” claim, and make the description concrete (what kind of place / what kind of staying).

- Rejected: `모임이 자연스러운 공간`
  - Reason: vague; “자연스러운” is soft and generic.
  - Direction: name a concrete effect (what kind of scene / why it’s different).

- Rejected: `카페가 아니라\n장면의 공간`
  - Reason: confrontational framing; reads like a slogan fight instead of a confident definition.
  - Direction: define what it is without negating what it is not.

- Rejected: `모임이 어울리는 자리, 기념이 어색하지 않은 밤. 그 장면을 공간이 먼저 만들어줍니다.`
  - Reason: the last sentence is English-first in logic (“space makes the scene”) and slightly promotional.
  - Direction: keep the first two fragments, but end with a human/scene-based closure.

- Rejected CTA label: `공간 살펴보기`
  - Reason: weaker intent than “보기/문의”; adds hedging.
  - Direction: keep CTA decisive.

- Rejected CTA label: `공간 문의` (Hero CTA)
  - Reason: hero first CTA should be exploration-first; inquiry is secondary.
  - Direction: keep hero CTA as “공간 보기”.

- Rejected alt: `모임과 체류가 가능한 바라쿠다 공간`
  - Reason: “가능한” reads like brochure language.
  - Direction: describe the scene in a plain noun phrase.

## 2) Intro (Space)
- Rejected (previously approved): `설명보다 먼저 분위기가 잡히는 공간. 그래서 모임이 더 편해집니다.`
  - Reason: copy-about-copy (“설명”), causal connector (“그래서”), explanatory tone; violates the cycle’s Korean-originalness bar.
  - Direction: remove meta commentary and causality; use short, scene-led Korean that can stand alone.

- Rejected eyebrow: `SCENE`
  - Reason: duplicates the later preview eyebrow; reduces hierarchy.
  - Direction: keep intro as “SPACE”.

- Rejected title: `우리의 모임이\n자연스럽게 놓이는 곳`
  - Reason: “놓이다” is slightly awkward and abstract; “자연스럽게” repeats the same softness.
  - Direction: use simpler verbs and fewer modifiers.

- Rejected title: `자리를 만들면\n공간이 따라옵니다`
  - Reason: slogan logic; “공간이 따라온다” feels translated and metaphor-heavy.
  - Direction: keep the claim grounded in the place, not the metaphor.

- Rejected description: `가벼운 방문, 작은 모임, 브랜드 장면까지 한 공간에서 무리 없이 됩니다.`
  - Reason: “무리 없이 됩니다” is unnatural Korean in this context.
  - Direction: use a natural verb: “됩니다/가능합니다” only if it reads like Korean, or split into two short sentences.

- Rejected CTA label: `공간 둘러보기`
  - Reason: acceptable but softer; “보기” is cleaner and consistent.
  - Direction: unify CTA verbs across homepage.

## 3) Signature section
- Rejected title: `바라쿠다의 네 장면`
  - Reason: correct but too generic; misses “difference by staying mode”.
  - Direction: anchor the section to “머무는 방식” differentiation.

- Rejected title: `한 공간, 네 가지 표정`
  - Reason: “표정” reads like decorative metaphor.
  - Direction: prefer plain, scene-based nouns.

- Rejected description: `모임, 기념, 브랜드, 라운지의 장면이 각자 다른 결로 남습니다.`
  - Reason: repetition (“장면” + “남습니다”), “결” stacking.
  - Direction: reduce repeated nouns; if two sentences, keep them short and plain.

- Rejected description: `같은 공간인데도 분위기는 달라집니다. 목적이 달라지면 장면도 달라지니까요.`
  - Reason: “니까요” adds casual justification; reads like explanation.
  - Direction: keep the idea but end decisively without justification tone.

- Rejected (previously approved): `같은 공간, 다른 장면. 목적이 달라지면 분위기도 달라집니다.`
  - Reason: too generic; could fit any venue; doesn’t anchor to the four defined scenes.
  - Direction: name the four scenes (or their categories) so the line is specific to this homepage system.
